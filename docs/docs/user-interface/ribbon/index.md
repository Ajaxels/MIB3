# Ribbon Tabs

*Back to [MIB](../../index.md) | [User interface](../index.md)*

This page provides an overview of the ribbon tabs available in the Microscopy Image Browser (MIB) graphical user interface (GUI). The ribbon, located at the top of the MIB window, groups file operations, dataset tools, image processing, segmentation workflows, and plugins into labeled tabs.

---

## Ribbon Overview

The MIB ribbon contains the following tabs:

- **[Home](file/index.md)**: file operations, image I/O tools, preferences, and access to help
- **[Dataset](dataset/index.md)**: adjust dataset properties and dimensions, perform alignment, and run dataset transformations
- **[Image](image/index.md)**: modify image settings, filters, and image-processing tools
- **[Model](model/index.md)**: work with segmentation models, convert between types, load, save, and quantify models
- **[Mask](mask/index.md)**: create and modify the mask layer to assist with segmentation tasks
- **[Selection](selection/index.md)**: manage the selection layer, a temporary layer supporting segmentation workflows
- **[Tools](tools/index.md)**: access analysis, measurement, and semi-automatic segmentation tools
- **[Plugins](../plugins/index.md)**: extend MIB with custom plugins and scripts

Help resources are available from the **[Help](help/index.md)** button on **Ribbon → Home**.
