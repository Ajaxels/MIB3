# Licenses

*Back to [MIB](../../index.md) | [Getting started](../index.md)*

Microscopy Image Browser (MIB) is distributed under specific licensing terms that vary depending on its usage and components. 
This section outlines the licenses for MIB and its dependencies, organized into three categories: MIB for MATLAB, 
MIB standalone, and external libraries or tools used by MIB.

## License Categories

### MIB for MATLAB
Details the licensing terms for running MIB within the MATLAB environment, including requirements for MATLAB 
licenses and usage conditions.

[Read more](license-mib-matlab.md)

### MIB Standalone
Covers the licensing for the standalone version of MIB, which does not require MATLAB, including 
distribution and usage permissions.

[Read more](license-mib-standalone.md)

### External Licenses
Lists licenses for third-party libraries, tools, and dependencies integrated with MIB, such as 
tools from [MATLAB Central File Exchange](https://se.mathworks.com/matlabcentral/fileexchange/?requestedDomain=), 
[Bio-Formats](https://www.openmicroscopy.org/bio-formats/), and others.

[Read more](licenses-ext.md)
