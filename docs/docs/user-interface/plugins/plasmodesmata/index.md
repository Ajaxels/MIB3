# Plasmodesmata Plugins

*Back to [MIB](../../../index.md) | [User Interface](../../index.md) | [Plugins](../index.md)*

---

The **Plasmodesmata** plugins in **Microscopy Image Browser (MIB)** provide tools tailored for analyzing plasmodesmata in plant biology, 
particularly in volume electron microscopy datasets. 
These plugins are located in the `Plugins/Plasmodesmata` folder of your MIB installation and are automatically detected when MIB starts.

## Available Plugins

- **Cell Wall Thickness**  
  Measures plant cell wall thickness in volume electron microscopy datasets, tailored for plasmodesmata 
  research in plant biology.  
  [Details](cellwall-thickness.md)
??? abstract "Reference"
    Andrea Paterlini and Ilya Belevich<br>Serial Block Electron Microscopy to Study Plasmodesmata in the Vasculature of Arabidopsis thaliana Roots.<br>
    Methods Mol Biol, 2022:2457:95-107. [doi: 10.1007/978-1-0716-2132-5_5.](https://link.springer.com/protocol/10.1007/978-1-0716-2132-5_5)


- **Spatial Control Points**  
  Generates sets of random points along an object’s centerline (e.g., plasmodesmata), useful for spatial distribution analysis.  
  [Details](spacial-control-points.md)
