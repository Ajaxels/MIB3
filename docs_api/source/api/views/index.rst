views — App Views
=================

The ``+views`` package contains the main application window class and
App Designer ``.mlapp`` panel components (in ``+components``).

.. note::

   ``.mlapp`` files (App Designer components under ``+views/+components/``)
   are not parsed by sphinxcontrib-matlabdomain.  Only the ``.m`` class
   wrappers are documented here.
