## This file can be used to override global config settings.
## Process:
## - Start MIB
## - Configure all required settings
## - Close MIB to store mib3.mat file with configuration settings
## - Copy mib3.mat to this location
## - Rename to "mib3_prefs_override.mat"
##
## When done, 
## if there is no mib3.mat file present under the user's directory, the file 'mib3_prefs_override.mat' 
## will be used to override default config settings generated upon MIB startup.
## If mib3.mat file is present, it will be used instead.
