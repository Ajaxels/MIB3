# Ribbon → Plugins

The **Plugins** tab in the MIB ribbon provides access to all installed plugins.
Plugins extend MIB with custom tools, batch workflows, and third-party integrations beyond the built-in feature set.

---

## Overview

![Plugins Ribbon Tab](../../../plugins/images/menuPlugins.png)

Plugins are organized in a two-tier category/plugin structure and are detected automatically at startup from the `Plugins` directory of your MIB installation.
Each category appears as a submenu; individual plugins are listed beneath it.

For full documentation — directory layout, managing plugins, writing your own, and the list of bundled plugins — see the dedicated section:

**[User interface → Plugins](../../../plugins/index.md)**
